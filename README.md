# 24智能产品1班 课表

手机端的单文件课程表：装到桌面像 App 一样，**断网也能用**，数据只存在手机本地（不上传任何服务器）。

- 打开本页 → 浏览器菜单 →「添加到主屏幕 / 安装应用」
- 支持单双周、**周次区间**（如 1-5 周 / 7-15 周），按当前周自动只显示该周该上的课
- 课程数据存浏览器 localStorage，可导出/导入 JSON 备份

> 想换成自己的课表：打开页面 → 右上角 ⚙ → 自己加课，或在设置里清空后重新录入。
> 修改页面内容后需要重新部署，手机上会提示「有新版本，刷新即可用上」。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 课程表本体（HTML+CSS+JS，无依赖、无构建） |
| `sw.js` | 离线缓存（Service Worker） |
| `manifest.webmanifest` | 安装清单（全屏、主题色） |
| `icon-*.png` | 桌面图标 |
